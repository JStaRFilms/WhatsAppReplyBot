# FR-005: Bounded autonomy and reactions

## Requirement

Permit autonomous assistant actions only in one confirmed conversation under an
expiring grant. Apply the same gates to text and reactions.

This is a MUS v1 requirement. Its product behavior is planned, not verified
by this documentation task.

## Acceptance

- A grant requires auto_reply, explicit owner confirmation, expiresAt and
  maxUnits in 1..20. Mode selection alone is not a grant.
- Reserve one unit per outbound text or reaction component. Reaction plus text
  costs two; split bubbles cannot evade the limit.
- Successful acceptance consumes a unit once. Definitive pre-acceptance
  failures release reservations; unknown outcomes retain them and cannot open
  capacity.
- Expiry, revocation, takeover, early completion or handover ends autonomous
  dispatch. Twenty units is a ceiling, never a target.
- Silence, emoji reaction, text, reaction plus text and handover are valid
  decisions. draft_only requires approval for reactions; never_reply permits no
  automated action.
- Fresh one-shot approvals during an active grant use its accounting. A bundle
  too large for remaining capacity needs a newly reviewed action, not silent
  truncation.

## Contracts

delegations successful_units/reserved_units/state, outbox_components and
validated action_json. Confirmed delegate proposals, delivery events and
per-conversation dispatch lock.

Use [Assistant_Architecture.md](../features/Assistant_Architecture.md) as the
shared schema and API/event contract. See the
[requirements index](../Project_Requirements.md) for scope and precedence.

## Verification

Test expiry, 1/20 limits, concurrent reservations, partial bundles, repeated
receipt events and unknown accounting across database restart. Outbound
WhatsApp reaction support needs later authorized device sends.

The evidence gates and test matrix are in
[Verification_Plan.md](../Verification_Plan.md). No live test is authorized
by this issue.

## Out of scope

Unbounded autonomous conversation, media sending, attempts to evade limits via
reactions or multiple bubbles.
