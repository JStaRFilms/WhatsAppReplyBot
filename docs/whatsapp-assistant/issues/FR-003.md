# FR-003: Explicit modes and latest-ten drafts

## Requirement

Apply explicit contact modes before selecting ten eligible unconfigured direct
conversations for automatic drafts. This default never authorizes sending.

This is a MUS v1 requirement. Its product behavior is planned, not verified
by this documentation task.

## Acceptance

- never_reply denies all AI access, drafts and automated text/reactions. draft_only
  produces drafts requiring approval. auto_reply requires a valid bounded grant
  for autonomy; otherwise produce drafts.
- Remove explicit modes, groups, broadcasts, unknown identities, AI-excluded
  contacts and chats blocked by hours/manual control before ranking eligible
  unconfigured contacts.
- Rank by last human conversation activity with conversation UUID tie-break. AI
  replies, draft generation and reactions do not increase recency.
- Select at most ten. Explicit modes never consume slots. Leaving the ten keeps
  existing drafts; other unconfigured chats get no automatic action.
- Owner manual sending remains available. Invalid timezone or permission data
  fails closed. Quiet hours block automatic generation/delivery; explicit owner
  drafting may proceed without send authority.

## Contracts

contacts explicit_mode/ai_excluded/permitted_hours_json/policy_version and
conversations last_human_activity_at/latest_ten_rank/control. Confirmed
change_mode proposals mutate policy and invalidate work.

Use [Assistant_Architecture.md](../features/Assistant_Architecture.md) as the
shared schema and API/event contract. See the
[requirements index](../Project_Requirements.md) for scope and precedence.

## Verification

Test 15 or more synthetic chats, explicit-mode precedence, tie ordering,
exclusions, rank movement, manual control and timezone boundaries. Historical
recency can seed ranking but cannot trigger old-message drafts.

The evidence gates and test matrix are in
[Verification_Plan.md](../Verification_Plan.md). No live test is authorized
by this issue.

## Out of scope

Automatic sending for the latest ten, timers that resume manual control and
group/status broadcast automation.
